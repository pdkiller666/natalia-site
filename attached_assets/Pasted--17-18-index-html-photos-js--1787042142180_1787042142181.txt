## 🐞 Баг №1 (реальный): шоурил может не подхватывать ссылку из админки

В `index.html`:
```js
if (data.video && data.video.videoUrl) { ... }
```
Но в `site.json` видео лежит **внутри** `sections.video`, а верхнеуровневого ключа `video` нет. Значит, условие никогда не срабатывает, и плеер берёт то, что захардкожено в HTML-атрибуте `data-video` (там заглушка `.../embed/VIDEO_ID`).

**Фикс (1 замена в index.html):**
```js
const vid = (data.sections && data.sections.video && data.sections.video.videoUrl) ? data.sections.video : data.video;
if (vid && vid.videoUrl) {
  const vf = document.querySelector('.video-frame');
  if (vf) vf.dataset.video = toEmbedUrl(vid.videoUrl);
}
```
После этого ссылка из админки («Секции → Видео») реально управляет плеером.

1. **Коммит `edebe7c` (Google Calendar в админке) — красный чек 0/1.** Зайдите в Actions и посмотрите, почему тот прогон упал; следующие коммиты зелёные, сайт задеплоен, но стоит убедиться, что это не сломанный workflow.
2. **Мёртвый код:** в `photos.js` осталась функция `decorateCases` — она нигде не вызывается (её работу теперь делает `renderCases` в index.html). Можно удалить для чистоты (на работу не влияет).
3. **Контент-заглушки:** аватары отзывов и фото команды — picsum; в галереях кейсов одно и то же сгенерированное фото ×3. Это то, что стоит заменить на реальные кадры через админку в первую очередь.
4. **Календарь:** `startYear/startMonth` захардкожены в index.html (2026/8). Через сезон придётся править вручную — можно позже вынести в админку рядом с `monthsToShow`.
