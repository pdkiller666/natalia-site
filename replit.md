# Наталья Тарасова — сайт ведущей мероприятий

Лендинг для event-ведущей: свадьбы, корпоративы, частные события.

## Стек

- Чистый HTML/CSS/JS — один файл `index.html`, без сборщиков и зависимостей
- Шрифты: Playfair Display + Manrope (Google Fonts)
- Деплой на GitHub Pages через GitHub Actions (`.github/workflows/`)

## Запуск на Replit

```bash
python3 -m http.server 5000
```

Workflow «Start application» настроен и запускается автоматически.

## Структура `index.html`

Весь код — в одном файле:
- Секции: hero, «Обо мне», видео, форматы, кейсы, отзывы, календарь дат, FAQ, контакты
- Интерактивный календарь (поддержка Google Calendar API — см. раздел 3 в комментариях файла)
- Schema.org разметка для SEO
- Яндекс.Метрика (место под код счётчика в `<head>`)

## Что нужно настроить вручную

1. **Контакты** — телефон, email, соцсети (поиск по `+7 921 000-00-00` и `hello@tarasova.event`)
2. **Фотографии** — заменить плейсхолдеры `picsum.photos` на реальные фото
3. **Google Calendar** — вставить API-ключ (инструкция в комментариях файла, раздел 3)
4. **Яндекс.Метрика** — вставить код счётчика в `<head>`
